# Security Policy

## Supported Versions

LearnTok is continuously deployed from the primary branch. Only the latest production release running on [learntok.in](https://www.learntok.in) receives security updates.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `master` (Latest Production) | :white_check_mark: |
| Older commits / forks        | :x:                |

---

## Reporting a Vulnerability

We take the security of LearnTok and our users' data seriously. If you discover a security vulnerability, please report it responsibly so we can address it before public disclosure.

### How to Report

* **GitHub Private Advisory (Preferred):** Open a private report under the repository's [Security > Report a vulnerability](https://github.com/vrBharat/learntok-web/security/advisories/new) tab.
* **Email:** If you cannot use GitHub Security Advisories, contact the maintainers directly at security@learntok.in or via the project author email.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. Any affected endpoints, components, or configurations.
4. Suggested fixes or mitigations, if known.

### Response & Handling Process

- **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.
- **Investigation & Triage:** We will validate the issue, assess severity, and provide status updates as we work on a fix.
- **Resolution:** Critical security patches will be deployed to production as soon as verified.
- **Disclosure:** Once a fix is deployed, we will coordinate public disclosure and provide proper credit to the reporter (if desired).

Please do not open public issues or pull requests detailing undisclosed vulnerabilities.
